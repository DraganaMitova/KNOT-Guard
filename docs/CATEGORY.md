# Category

KNOT Guard is an authority-governed execution runtime.

It is best understood as a state-transition firewall for sensitive software actions: a protected action may execute only when authority, scope, token consumption, and audit all agree.

## KNOT Guard Is Not

- a vulnerability scanner
- a Linux hardening script
- a dependency auditor
- an IAM replacement
- a CI wrapper
- a policy linter
- a generic sandbox

Those tools inspect systems, dependencies, hosts, or pipelines.

KNOT Guard governs whether a sensitive action is allowed to become reality.

## KNOT Guard Is

- a runtime gate for dangerous backend actions
- a replay-resistant execution boundary
- a scope-bound authority layer
- a receipt-producing transition runtime
- an audit-chain producer for sensitive state changes
- a safety layer between AI/tool intent and real-world action

## Core Sentence

KNOT Guard makes sensitive software actions pass through authority, scope, token consumption, and audit before execution is allowed inside the configured runtime boundary.
